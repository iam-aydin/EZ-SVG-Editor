# EZ SVG Editor

An ultra-lightweight, single-file vector graphic and style workbench built entirely in standalone HTML, CSS, and vanilla JavaScript. No node modules, build tools, or external dependencies required.

---

## 🚀 Live Demo

Launch and use the editor directly in your web browser without downloading or installing anything:

👉 **[Launch EZ SVG Editor Online](https://iam-aydin.github.io/EZ-SVG-Editor/app.html)**

*(Alternative mirror via GitHack: [Open `app.html](https://raw.githack.com/iam-aydin/EZ-SVG-Editor/main/app.html)`)*

---

## ✨ Features

* **Zero Setup:** Runs completely client-side in a single self-contained `app.html` file.
* **Interactive Canvas Stage:** Infinite vector viewport with smooth panning, multi-level zoom (up to 800%), and view locking.
* **Visual Styling & Colors:** Real-time color picker, fill modes (solid, gradient, none), fill opacity, stroke width, and stroke colors.
* **Layer Management:** Visual layer ordering stack with drag-and-drop depth control (Bring Forward, Send Backward, Front, Back).
* **Transform & Precision Controls:** Visual rotation handles, precision coordinate translation ($X$, $Y$), and angle sliders.
* **Gradient Defs Editor:** Built-in gradient definition editor to inspect, customize, and add color stops to SVG gradients on the fly.
* **Undo / Redo & Keybindings:** Unlimited history stack with standard hotkeys (`Ctrl+Z`, `Ctrl+Y`, `Del`).
* **Flexible Import & Export:**
* Import `.svg` files directly or paste SVG code strings.
* Export clean vector `.svg` files or copy full SVG markup to clipboard.

## 💻 Quick Start (Local Setup)

1. **Clone the repository:**
```bash
git clone https://github.com/iam-aydin/EZ-SVG-Editor.git

```


2. **Run the app:**
Simply double-click `app.html` or open it in any web browser.

## 🛠️ Hosting on Your Own GitHub Pages

To host this repository on your own GitHub Pages:

1. Go to your repository **Settings** on GitHub.
2. Select **Pages** from the left sidebar.
3. Under **Build and deployment** > **Branch**, select `main` (or `master`) and `/ (root)`.
4. Click **Save**. Your editor will be live at `https://<your-username>.github.io/<repo-name>/app.html`.
